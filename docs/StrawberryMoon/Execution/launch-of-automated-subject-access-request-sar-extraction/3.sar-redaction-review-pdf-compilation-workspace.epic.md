# SAR Redaction Review & PDF Compilation Workspace

## Strategic Context
Practice administrators and GP Partners require an intuitive, low-friction interface to verify automated redactions, apply manual masks, and compile an audit-ready, flattened PDF for disclosure. Providing a synchronized dual-pane review workspace with one-click redaction toggles allows the practice team to complete verification in 2-3 minutes while ensuring redacted data cannot be recovered by reverse-engineering exported documents.

## Success Criteria
- Reduction of average practice review and redaction time to under 3 minutes per completed SAR.
- 100% irreversibility of redacted text and metadata in compiled PDF/A disclosure packages.

## Scope

### In Scope
- Dual-pane review interface presenting chronological EHR text alongside interactive redaction chips.
- One-click redaction toggle between visible text and irreversible `[REDACTED]` visual blocks.
- Manual click-and-drag text selection for custom redaction masks.
- Server-side PDF/A compilation with true graphical flattening and metadata sanitization.

### Out of Scope
- Direct patient-facing download portal for data subjects (dispatched via practice workflow).
- Editing or modifying underlying clinical consultation text.

## Acceptance Criteria
WHEN a reviewer opens a staged SAR, the Review Workspace SHALL display the chronological clinical record with all automated redaction candidates highlighted as interactive chips.

WHEN a user clicks an interactive redaction chip, the Review Workspace SHALL toggle the redaction state between masked `[REDACTED]` and unmasked text, updating the live preview immediately.

WHERE a reviewer selects custom text with mouse highlight, the Review Workspace SHALL create a user-defined redaction entity and record the action in the audit log.

WHEN the user triggers PDF compilation, the Report Synthesis Engine SHALL render a flattened PDF/A document with all redacted text permanently removed from the underlying document byte stream.

IF any mandatory safeguarding flag remains unreviewed, THEN the Review Workspace SHALL disable compilation and display an alert banner directing the user to the flagged section.

## Business Rules
- Exported PDF artifacts must strictly conform to PDF/A archival standards with all text layers under redactions completely excised, not merely obscured with black overlays.
- Document compilation must be cryptographically checksummed (SHA-256) upon generation for legal defensibility.
- Auto-save state must persist review drafts across active user sessions.

## Dependencies
- React/Next.js frontend design system adhering to WCAG 2.1 AA and NHS Digital Service Manual standards.
- Puppeteer / PDF generation service running within UK-sovereign Fargate cluster.
