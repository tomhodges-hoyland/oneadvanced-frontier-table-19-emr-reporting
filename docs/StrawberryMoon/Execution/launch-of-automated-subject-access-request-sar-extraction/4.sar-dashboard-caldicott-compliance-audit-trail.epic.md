# SAR Dashboard & Caldicott Compliance Audit Trail

## Strategic Context
Failing to respond to Subject Access Requests within the statutory 30-day window exposes practices to Information Commissioner's Office (ICO) regulatory enforcement and financial penalties. A centralized practice dashboard with dynamic SLA countdown timers, workflow status tracking, and comprehensive Caldicott-compliant audit logging gives practice managers full visibility and defensible accountability across all in-flight requests.

## Success Criteria
- Zero ICO SLA breach incidents across active practices.
- 100% capture of user access, redaction decisions, and document disclosures in an immutable Caldicott audit log.

## Scope

### In Scope
- Practice-wide SAR dashboard queue with status filters (New, Processing, In Review, Ready for Sign-Off, Completed).
- Dynamic 30-day statutory countdown indicators with amber/crimson SLA threshold warnings.
- Caldicott Guardian audit logging tracking user ID, patient NHS number, timestamps, and redaction changes.
- Exportable compliance audit reports for ICO and CQC inspections.

### Out of Scope
- Non-SAR workflow queues (handled in separate reporting modules).
- Financial ledger and payment escrow processing (SARs are statutory non-fee requests under UK GDPR).

## Acceptance Criteria
WHEN a new SAR is created, the Dashboard Service SHALL initialize a 30-day statutory countdown timer and set initial status to New.

WHERE the remaining time for a SAR is 5 days or fewer, the Dashboard Service SHALL render an amber warning badge on the request row.

IF a SAR exceeds the 30-day deadline without completion, THEN the Dashboard Service SHALL transition the SLA badge to a crimson breach state and trigger an alert notification.

WHEN any user views, modifies a redaction, or exports a SAR document, the Audit Service SHALL write an immutable log entry recording user ID, timestamp, action type, and patient identifier.

## Business Rules
- Audit logs must be retained in immutable storage with write-once-read-many (WORM) controls for minimum statutory retention periods.
- Access to SAR management dashboard must require NHS CIS2 authentication with appropriate RBAC role assignment.
- SLA countdown calculations must account for UK bank holidays and standard calendar days.

## Dependencies
- AWS Aurora PostgreSQL with Row-Level Security and CloudWatch immutable audit log streaming.
- NHS CIS2 federated authentication integration.
